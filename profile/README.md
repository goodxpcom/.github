# GoodXP

GoodXP is an independent studio making games, apps, and systems.

Attention to detail. An eye for beauty. The patience to get things right.

## Projects

- **[Handful of Dice](https://www.goodxp.com/projects/handful-of-dice)**: a tactile digital dice tray for tabletop gamers. [Wishlist it on Steam](https://store.steampowered.com/app/5294140/Handful_of_Dice/).
- **[Text Atlas](https://www.textatlas.app/)**: civilization-defining texts, rebuilt book by book.
- **[FlowMind](https://www.flowmind.pro/)**: proof of effort, recorded while it happens.

More games and experiments are on [goodxp.com](https://goodxp.com).
